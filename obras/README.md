# Obras y ediciones

Esta sección documenta las obras de José Baroja y sus distintas ediciones.

## Criterios

- Una fila por edición o manifestación bibliográfica identificable.
- Transcribir el título tal como aparece en la fuente.
- Registrar autoría, editorial, lugar, año, ISBN y otros datos solo cuando consten en el registro consultado.
- Conservar el enlace directo al catálogo o fuente editorial.
- No confundir una obra con sus distintas ediciones ni con reseñas o menciones.
