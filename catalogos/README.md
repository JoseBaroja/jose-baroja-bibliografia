# Catálogos de bibliotecas

Aquí se documentarán registros individuales localizados en catálogos de bibliotecas nacionales, universitarias, públicas y especializadas.

## Regla fundamental

Cada entrada debe apuntar al registro concreto del catálogo. La existencia de una biblioteca o de una página institucional no demuestra por sí sola que posea o catalogue una obra determinada.
