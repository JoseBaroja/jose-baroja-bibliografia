# José Baroja

**Escritor | Magíster en Letras, mención Literatura — Pontificia Universidad Católica de Chile**

Escritor interesado en la literatura, la creación narrativa, la lectura crítica y la circulación internacional del libro. Este perfil reúne proyectos de documentación bibliográfica, registros de autoridad y seguimiento de la recepción crítica de mi obra.

## Proyectos

### [Bibliografía y registros de autoridad de José Baroja](https://github.com/JoseBaroja/jose-baroja-bibliografia)
Proyecto de investigación documental para organizar y verificar:
- Obras, ediciones e ISBN.
- Registros en catálogos de bibliotecas nacionales y universitarias.
- Identificadores de autoridad (VIAF, ISNI, BNE, LCCN y otros).
- Artículos, reseñas, tesis y recepción crítica independiente.

## Sobre este espacio

Este GitHub funciona como archivo de trabajo público y trazable. Los datos bibliográficos se incorporan con enlaces a sus fuentes; las pistas pendientes, discrepancias y registros no verificados se identifican expresamente para evitar confundirlos con información confirmada.
